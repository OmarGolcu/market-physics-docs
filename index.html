Feature Libraries

Three Python libraries that turn OHLCV data into descriptive features — physics-inspired estimators, the classic technical-analysis canon, and non-repainting price-action structure — documented from their source, with every chart computed by the library itself on deterministic synthetic data.

3 libraries 199 feature functions 198 registry entries source 37730ca python 3.12+ pandas · numpy
Scope

Every output of all three libraries is a descriptive feature, not a trading signal. None of them is a buy/sell generator, a strategy framework or a backtester, and no output carries a claim of predictive value. Black Hole is the app that composes them into strategies; that composition is outside these pages.

min_bars is the measured tail-slice reach at default parameters — the smallest history from which a streaming tail reproduces the full-series value. For an unbounded_history entry it is only a readiness floor: those causal state machines have no finite reach, and the engine feeds them the whole buffer.

Not registered
