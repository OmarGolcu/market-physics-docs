TA Classic

The classic technical-analysis canon — moving averages, Wilder's directional movement and RSI, MACD, stochastics, ATR, Bollinger, OBV, VWAP — as 14 indicators under one hard contract: causal (bar t uses bars ≤ t), with a measured tail-slice reach published per indicator, and deterministic answers on degenerate flat windows. Same (name, values, metadata) result shape as market_physics; an independent package.

Scope

Every output is a descriptive feature, not a trading signal. ta_classic computes the classic technical-analysis canon under a hard contract — causal, measured reach, deterministic flat-market answers — for research pipelines. It is not a buy/sell system, not a strategy framework and not a backtester, and no threshold on any of these indicators carries a claim of predictive value.

Why a classic-TA library

market_physics describes market state with borrowed physical measurements, and price_action with the geometry of swings, levels and zones. Neither speaks the vocabulary most of the trading literature is written in: RSI against 30 and 70, a stochastic against 20 and 80, ADX against 25, the close against its Bollinger bands, moving-average and MACD crossovers. Much of what these indicators measure is already present in the other libraries in another form; what they add is fixed, widely shared parametrisations with absolute reference levels — a different kind of statement from a level read against a feature's own recent history. ta_classic is a small library of exactly that canon, held to the same causality and streaming contract as the other two libraries.

The roster is the design report's T1 core: 14 indicators in four families — trend (sma, ema, adx, di_signed, donchian_position), momentum (rsi, macd, stoch), volatility (atr_pct, bb_percent_b, bb_bandwidth) and volume (obv_flow, vwap_deviation, volume_ratio). The list is deliberately short. Canonical items that already exist elsewhere in another form were left out: Williams %R (%K − 100, an affine copy of the stochastic), rate of change and momentum (close to market_physics' market_velocity), the rolling standard deviation (brownian_volatility), and ZigZag and fractal pivots (causal versions already live in price_action). Two canonical forms that conflict with the contract were adapted rather than dropped: the cumulative OBV line, which has no finite reach at all, became a windowed flow, and Wilder's recursive smoothing, which has no exact finite reach, became a rolling mean by default wherever the indicator survives the change (see The Wilder policy below).

The package is independent: pandas and numpy only, Python 3.12+, version 0.1.0 (declared frozen at this commit; a 0.1.1 carrying source fixes is scheduled). Its result type has the same (name, values, metadata) shape as market_physics' IndicatorResult, so a consumer can handle results from both libraries the same way, but the class is a copy, not an import: the test suite pins the field order and scans every source file for an import of market_physics. TA-Lib is used only as a test oracle — an optional suite that skips itself when TA-Lib is not installed — and is not a dependency.

Several entries overlap knowingly with a feature in the other libraries: their physics twin. Some overlaps are exact. Bollinger %B is an affine transform of market_physics' mean_reversion_pressure on price at the same window (except on exactly constant windows, where %B reads 0.5 and mean_reversion_pressure reads NaN), and obv_flow equals volume_imbalance(direction_source="close_change", normalize=False) at the same window. Others measure the same idea a different way (ADX and path_efficiency; the range-based ATR and the standard-deviation-based volatility features). Inside the library, stochastic %K is donchian_position scaled by 100 at the same window: one formula, implemented twice, equal up to rounding (default windows 14 and 20). These entries are kept for their canonical vocabulary and thresholds. Where the sources document a twin, the function's entry names it and what differs, so an analysis that draws on several libraries can treat a twin pair as correlated evidence rather than as two independent findings.

One contract, every indicator

Every function takes a pandas DataFrame with canonical lowercase columns (open, high, low, close, volume; each function validates only the ones it reads) plus keyword parameters, and returns an IndicatorResult:

Same shape, thinner metadata — the field names and their order match market_physics, and a test pins them. Unlike market_physics, the metadata carries parameters only: there are no formula or interpretation strings. The constructor type-checks all three fields and raises TypeError on a wrong type.

Five points make up the contract. The package docstring states them and the library's own test suite pins them:

  • Causality — the value at bar t uses bars ≤ t only. Computing on df.iloc[:k] reproduces the first k values of the full computation exactly, for every k at or above the function's computability floor (shorter prefixes raise InsufficientDataError). The suite checks this on random data, across a flat patch, and by rewriting the future of a frame and comparing the past.
  • Measured tail-slice reach — ta_classic.reach.min_bars publishes, per indicator and parameter set, the history from which a recomputation over only the last min_bars rows is meant to reproduce the full-series value within the relative gate |d| ≤ max(1e-12, 1e-9·|ref|). The suite measures it with a dense-L reach finder at the default parameters. Reproduction is not bit for bit, and for the Bollinger pair not always within the gate: on a seeded 1500-bar frame, tails of sma, adx, stoch %D, the Bollinger pair, obv_flow, vwap_deviation and volume_ratio differed from the full pass in the last bits at some or all of 300 end points, while di_signed, donchian_position, Cutler rsi, stoch %K and atr_pct matched exactly there; on another seed di_signed and atr_pct showed last-bit differences too. On long frames, and on calm or tick-quantised windows, the full pass's rolling standard deviation carries accumulator residue, and bb_percent_b / bb_bandwidth tails then differ from it by more than the gate (up to about 6e-6 relative on a 60,000-bar walk).
  • Dust and flat-market snaps at source — an exactly degenerate window (flat close, HH = LL, zero true range, zero volume) is detected with order statistics — rolling max equal to rolling min, or rolling max equal to 0 for a non-negative input — which accumulate no floating-point residue. Its value is snapped to a fixed answer: 0.5 for the Donchian position and %B, 50 for %K and RSI, 0 for ADX, DI, ATR %, bandwidth, OBV flow and VWAP deviation, and 1.0 for the volume ratio of a dead-volume window. Only exact degeneracy is snapped; a nearly flat window is computed as it is.
  • The Wilder policy — rolling-mean adaptations by default, canonical exponential averages only where the indicator does not exist without them, and every deviation labelled. See the next section.
  • One function, one series — a multi-output indicator takes a component choice instead of returning a frame: macd(component="line" | "signal" | "hist") and stoch(component="k" | "d"). Each call computes one series.

The Wilder policy

J. Welles Wilder Jr.'s New Concepts in Technical Trading Systems (1978) introduced RSI, the average true range and the directional movement system, all smoothed with his recursive average — an exponential average with α = 1/n. An exponential average never forgets its seed. Its value at bar t depends on every bar since the start of the frame, so two frames that start on different bars disagree by an amount that shrinks geometrically but never reaches zero. That sits badly with the reach contract: no finite history removes the seed's influence, it can only shrink it below the gate.

At = At−1 + (xt − At−1)/n   — Wilder's smoothing: α = 1/n, infinite memory
Et = α·xt + (1 − α)·Et−1,  α = 2/(n+1)   — the standard EMA (ema, macd)
Mt = (xt−n+1 + … + xt)/n   — the rolling-mean adaptation: finite memory, n bars

The library settles the conflict per indicator, following §6 of the design report, and the code names each choice:

  • Rolling-mean adaptation (the default) — rsi with smoothing="sma" (Cutler's variant), adx (both smoothing layers), di_signed and atr_pct. Wilder's building blocks — gains and losses, +DM and −DM, the true range — are unchanged; only the smoothing is a rolling mean. These values deviate from canonical Wilder and are labelled that way. Their reach is finite and equals the first-valid index + 1.
  • Canonical EMA where the indicator requires it — ema (α = 2/(window+1)) and macd (three such averages; an SMA-smoothed MACD would be a different indicator). Both are seeded with the first value of the frame (pandas ewm(adjust=False)), emit from bar 0, and publish a closed-form effective-reach bound (checked by measurement only at the defaults) instead of a first-valid position.
  • The pilot — rsi(smoothing="wilder") is Wilder's own recursion (ewm(alpha=1/window, adjust=False)), seeded with the first gain and loss. Bar 0 is NaN and values start at bar 1. It is the only Wilder-recursive option in 0.1.0.

How far the adaptations move from the canon was measured against TA-Lib on three seeded 3000-bar random walks (seeds 7, 42 and 99). Cutler RSI correlated with Wilder RSI at 0.888–0.896. The rolling-mean ADX correlated with Wilder's ADX at 0.73–0.75 but sat higher: a median of 33.6–36.4 against 23.6–25.7, with 71–78 % of bars above 25 against 44–52 %. The canonical "ADX above 25" level therefore does not carry over; the level crossed by the same share of bars as Wilder's 25 was 35.4–37.0 on these walks. The sign of di_signed matched the sign of Wilder's DI+ − DI− on about 86 % of bars.

One deliberate deviation inside the pilot — when the trailing window + 1 closes are all equal, RSI reads exactly 50 in both modes. In the Cutler mode that is the natural 0/0 answer. In the Wilder mode the recursive averages would otherwise keep their pre-flat ratio indefinitely, so the output is snapped to 50 instead. Only the output is snapped: the averages keep their state, decaying together through the flat stretch, so the first bar that moves again blends the pre-flat ratio with the new change rather than starting from 50. After a short flat stretch that reads near the pre-flat level; after a long one the new change dominates.

Measured reach: min_bars

A streaming consumer does not recompute an indicator over its whole history on every bar; it recomputes over a tail. min_bars is the length of that tail. For the rolling class it is the smallest L for which the indicator computed on only the last L rows reproduces the full-series value at the final bar within the relative gate; for the EMA class it is a closed-form bound meant to sit at or above that L. It is a tail-slice reach, not the first-valid position, and the two are tied (reach = first-valid index + 1) only for the rolling class.

Rolling class — every entry except ema, macd and Wilder-mode rsi. Each operation is a fixed-window rolling statistic, so the reach is the first-valid index + 1, and the suite requires the measured reach to equal the published one. EMA class — ema, macd and rsi(smoothing="wilder"). No exact finite reach exists, but the seed's weight decays as (1 − α)L, and because the gate is relative the effective reach is finite. The library publishes a closed-form bound:

L(α, d) = ⌈ d · ln 10 / −ln(1 − α) ⌉   — bars for the seed weight to fall d decades
ema: L(2/(w+1), 10)  ·  rsi wilder: L(1/w, 10) + 1   — one decade spare over the 1e-9 gate; +1 for the price difference
macd: L(2/(slow+1), 14) + L(2/(signal+1), 14)   — two decay stages summed; the fast span does not enter

At the defaults this gives 231 bars for EMA(20), 312 for Wilder RSI(14) and 564 for MACD(12/26/9) — 419 for the slow EMA plus 145 for the signal EMA. That is about 11·(w+1) for an EMA (11.0 at span 20, approaching 11.5 at large spans) and about 22·w for Wilder RSI at w = 14 (approaching 23·w at large windows, less at small ones). MACD gets 14 decades per stage because its value crosses zero: near zero the gate falls back to its absolute floor of 1e-12, which at prices of order 100 needs about 14 decades of relative decay rather than 9.

This is the REACH_EXCEEDS_FIRST_VALID doctrine: for the EMA class, min_bars may — and must — lie far past the first valid bar. ema and macd emit from bar 0 and Wilder rsi from bar 1, but those early values are seed-contaminated and change if the frame starts on a different bar. The library publishes the reach and does not mask early values, so a consumer that treats "not NaN" as "ready" reads seed-dependent numbers.

What "measured" covers — the suite's reach finder runs at the default parameters on one seeded random-walk frame. There the rolling class measures exactly as published and the EMA class at or below it; at any other parameters an EMA-class number is the formula's, not a measurement. Re-checked on ten seeds for these docs, EMA(20), EMA(200) and MACD(12/26/9) stayed inside the gate at their published reach at every end point tested. Wilder RSI did not always. At window 14, a few end points on several seeds exceeded the gate (9 of about 27,000 across 6 of 10 seeds in a full scan, worst 1.9e-9 relative), and at windows 2 and 3 every seed had end points outside it. The spare decade covers a seed error up to a few times the current value's scale, which a ratio of two small decaying averages does not guarantee. min_bars also raises ValueError for a span of 1 (α = 1), which ema, Wilder rsi and macd's signal_window themselves accept.

Conventions & errors

  • Columns — canonical lowercase names only. There is no column-mapping parameter, so a frame with Close instead of close raises MissingColumnError. Extra columns are ignored. ta_classic.core.OHLCV_COLUMNS is the reference tuple.
  • Warm-up — leading values are NaN until the window is full (table above), and the output index is the input index. The EMA class has no NaN warm-up (Wilder RSI has one NaN bar); its readiness is min_bars, not the first value.
  • Windows are bars — every window, span and smooth counts bars of whatever timeframe you pass in, never clock time.
  • Missing input values — nothing is filled or dropped. A rolling statistic whose window contains a NaN is NaN for that window's length — except the true range, which takes the largest of its three legs and skips a missing one, so a NaN high or low still yields a true range and atr_pct keeps emitting values; the exponential entries (ema, macd, Wilder rsi) are pandas ewm and carry their last value across a NaN bar instead of emitting NaN.
  • Parameter validation — integer parameters must be true integers (NumPy integers are accepted; True, floats and strings are refused) and meet their minimum: window ≥ 1 for most functions, window ≥ 2 for the Bollinger pair, slow ≥ 2 and fast < slow for MACD. num_std must be a number greater than 0 (NaN is refused). Choice parameters (smoothing, component) must be one of their listed strings. All of these raise ValueError.
  • Errors — ta_classic.exceptions defines TAClassicError and two subclasses: MissingColumnError (attributes missing, required) and InsufficientDataError (available, required). Parameter errors are plain ValueError and a non-DataFrame input is a TypeError; neither subclasses TAClassicError, so catching the base class alone does not catch them.
  • Computability floor — a frame shorter than a function's floor raises InsufficientDataError. For the rolling class the floor equals min_bars, so a frame of exactly min_bars rows computes with a valid final value; ema and macd need one row, Wilder rsi two.
  • Imports — the 14 indicators, IndicatorResult, min_bars and MIN_BARS_DEFAULTS are exported from ta_classic; ema_decay_bars lives in ta_classic.reach, the exceptions in ta_classic.exceptions, the validators in ta_classic.core.

trend

Classic TA canon — moving averages, Wilder's directional movement, Donchian channels · 5 indicators

Trend analysis is the oldest layer of the technical canon, and its instruments answer three different questions. The simple and exponential moving averages ask where price stands against its own recent average. Richard Donchian's channel — the highest high and lowest low of the last N bars — asks where price sits inside its recent range. J. Welles Wilder Jr.'s directional movement system (1978) asks how strongly one side dominates, by comparing how far each bar's high extends above the previous high with how far its low extends below the previous low.

+DMt = Ht − Ht−1 if it exceeds Lt−1 − Lt and is > 0, else 0   — −DM mirrored; an inside bar has neither
DI ratio = (m⁺ − m⁻) / (m⁺ + m⁻),  m± = meann(±DM)   — the 100/ATR factor of DI± cancels
ADX = meann(100 · |DI ratio|)   — both layers rolling means, not Wilder's recursion
Donchian position = (C − LLn) / (HHn − LLn)   — current bar inside the channel

sma is the plain rolling mean of the close. ema is the recursive average with α = 2/(window + 1), seeded with the first close of the frame it is given: it has a value from bar 0, but that value depends on where the frame starts until the seed has decayed — 231 bars at span 20, which is its published min_bars. Both live on the price scale and are unbounded; the canonical readings are comparisons, the close against an average or a fast average against a slow one.

+DM, −DM and the true range are Wilder's own definitions, including the rule that only the larger of the two extensions counts and only when it is positive; bar 0 is NaN because both need the previous bar. The smoothing is not Wilder's. Both layers of adx — the DM averages and the average of DX — are rolling means over window bars, which gives a finite reach of 2·window (28 at the default 14). di_signed folds DI+ and DI− into one ratio in [−1, 1]: its sign names the dominant side and a zero crossing is the classic DI crossover. It has a single smoothing layer, so its reach is window + 1. Because DI+ and DI− share the 100/ATR factor, the true range cancels from the ratio; both functions depend on highs and lows only, although they still validate a close column. di_signed reads exactly 0 on a window with no directional movement, and so does each DX that adx averages; adx itself reads 0 once every DX in its own window is 0.

The rolling-mean smoothing moves the levels, not only the reach. Against TA-Lib's Wilder ADX on three seeded 3000-bar random walks, this ADX had a median of 33.6–36.4 where Wilder's had 23.6–25.7, and the level crossed by the same share of bars as Wilder's 25 was 35.4–37.0. The canonical "ADX above 25" does not carry over unchanged, and both directional entries are labelled as deviating from canonical Wilder.

donchian_position places the close inside the channel of the trailing window bars, current bar included: 0 at the lowest low, 1 at the highest high, 0.5 when the channel has no height. The extremes are order statistics, so a full pass and a tail pass agree exactly. Because the channel contains the current bar, a close above the previous channel high reads 1 − (H − C)/(H − LL) rather than 1, so the position is not a breakout flag. It is the same formula family as stochastic %K scaled to [0, 1], and both names are published on purpose.

When to reach for this family: trend state in the canon's own units — where the close sits against its averages and its channel, which side's directional movement dominates and how strongly — as non-repainting per-bar series with a published reach.

momentum

Classic TA canon — Wilder's RSI, Appel's MACD, Lane's stochastic oscillator · 3 indicators

Momentum oscillators turn the recent path of the close into a bounded or zero-centred number with fixed reference levels. Wilder's Relative Strength Index (1978) compares average gains with average gains plus average losses. Gerald Appel's MACD takes the difference between a fast and a slow exponential average and smooths it once more into a signal line. George Lane's stochastic places the close inside its recent high–low range. Their canonical thresholds — 30 and 70, the signal-line and zero crossings, 20 and 80 — are absolute, which is what sets them apart from a feature read against its own history.

RSI = 100 · Ḡ / (Ḡ + L̄)  ≡  100 − 100/(1 + RS)   — Ḡ, L̄: average gain and loss over the window
line = EMAfast(C) − EMAslow(C),  signal = EMAsig(line),  hist = line − signal
%K = 100 · (C − LLn) / (HHn − LLn),  %D = meansmooth(%K)   — the fast stochastic

rsi is computed in the first form, algebraically the textbook one, so that a zero denominator is tested in one place. The default smoothing="sma" averages gains and losses with rolling means (Cutler's variant): the first value is at bar window and the reach is window + 1. smoothing="wilder" is the canonical recursion with α = 1/window, seeded with the first gain and loss; bar 0 is NaN, values start at bar 1 — where a single up or down change reads 100 or 0, and an unchanged close reads 50 — and the published reach is 312 bars at window 14. Measured against TA-Lib's Wilder RSI on three seeded random walks, the Cutler default correlated at 0.888–0.896.

When the trailing window + 1 closes are all equal, both modes read exactly 50. For the Cutler mode that is the natural 0/0 answer. For the Wilder mode it is a deliberate deviation: two identically decaying averages would keep their pre-flat ratio for ever, a memory with no finite reach. Only the output is snapped. The averages keep their state, decaying together through the flat stretch, so the first bar that moves again blends the pre-flat ratio with the new change rather than starting from 50: after a short flat stretch it reads near the pre-flat level, after a long one the new change dominates.

macd uses canonical EMAs only; an SMA-smoothed MACD is a different indicator. All three averages are seeded with the first value of the frame, so line, signal and histogram are 0 at bar 0 and exist from there, while the published reach at 12/26/9 is 564 bars: the slow EMA and the signal EMA as two decay stages, 14 decades each, summed. TA-Lib seeds its EMAs with an SMA instead, so the two differ on early bars and converge as the seed decays; the library's oracle test compares them only past the published reach. One call returns one component — line, signal or hist — and fast must be smaller than slow.

stoch is the fast stochastic: %K over the trailing window bars and %D a plain rolling mean of %K over smooth bars, which matches TA-Lib's STOCHF rather than the slow stochastic that smooths %K first. A range with no height reads %K = 50. %K is donchian_position scaled by 100, and Williams %R (%K − 100) is left out of the roster as its affine copy.

When to reach for this family: momentum in its canonical units — how gains weigh against losses, whether the fast average has pulled away from the slow one, where the close sits in its recent range — with the fixed reference levels the literature uses.

volatility

Classic TA canon — Wilder's average true range, Bollinger Bands · 3 indicators

The canon measures volatility two ways. Wilder's true range (1978) widens a bar's high–low range to include any gap from the previous close, so a market that jumps between bars is not mistaken for a quiet one; its average is the ATR. John Bollinger's bands place an envelope a fixed number of standard deviations around a simple moving average; their two standard derivatives are %B, where the close sits inside the envelope, and bandwidth, how wide the envelope is relative to its middle — the measure behind the "squeeze".

TRt = max(Ht − Lt, |Ht − Ct−1|, |Lt − Ct−1|)   — the range, gaps included
ATR % = 100 · meann(TR) / Ct   — a rolling mean, not Wilder's recursion
%B = (C − (M − kσ)) / (2kσ),  bandwidth = 2kσ / M   — M = SMAn, σ = population std, k = num_std

atr_pct averages the true range with a rolling mean of window bars and divides by the current close, so the value is a percentage that compares across price scales. Bar 0 has no previous close and is NaN; the first value is at bar window and the reach is window + 1. A window of all-zero true ranges — a completely flat patch — reads exactly 0. The rolling mean replaces Wilder's recursive average on purpose: it keeps the reach finite, and the values are labelled as the rolling-mean ATR rather than Wilder's.

Both Bollinger functions use the population standard deviation (ddof = 0), the classic definition and the one TA-Lib's BBANDS computes; a sample standard deviation would widen the band by √(w/(w−1)), about 2.6 % at window 20. bb_percent_b is 0 on the lower band and 1 on the upper and is deliberately not clamped: a close outside the bands reads below 0 or above 1. bb_bandwidth is the band width over the middle band. An exactly constant window is detected with rolling max = rolling min and snapped — %B to 0.5, bandwidth to 0 — and both need window ≥ 2 and num_std > 0.

Two of the three overlap closely with market_physics features. %B is an exact affine transform of the rolling z-score that mean_reversion_pressure computes on price at the same window: %B = 0.5 + z·√(w/(w−1)) / (2·num_std), the root converting its sample deviation to the population one used here. They part only where that z-score is undefined: on a constant window it is NaN while %B snaps to 0.5. Bandwidth is a relative of brownian_volatility, with one difference that matters: that feature is the deviation of returns, while bandwidth is the deviation of the close level over its average, so a steady trend inside the window widens the band without any rise in return volatility. ATR, for its part, is range-based and counts gaps, where the physics volatility features are built on standard deviations of returns (market_temperature multiplies one by the mean intrabar high–low range, which leaves gaps out).

The flat-window snap catches only exact constancy. On ordinary data the Bollinger pair is reproduced by a tail within the relative gate but not bit for bit — in a check on a seeded frame, none of 300 end points matched exactly — so two computations of %B that should land exactly on 0, 0.5 or 1 are not guaranteed to agree on which side of it they fall.

When to reach for this family: volatility in the canon's units — the average bar range including gaps, the close's place inside its standard-deviation envelope, and how wide that envelope is — when a fixed reference such as the 0 and 1 band edges is the point.

volume

Classic TA canon — Granville's on-balance volume, VWAP, volume spikes · 3 indicators

Volume analysis in the canon asks whether participation confirms price. Joseph Granville's on-balance volume (1963) keeps a running total that adds a bar's volume when the close rises and subtracts it when the close falls. The volume-weighted average price is the trading desk's benchmark: the average price paid per unit traded, usually built from the typical price (H + L + C)/3. The plainest instrument of all compares a bar's volume with its recent average — the vocabulary of the volume spike.

OBV flow = Σn sign(Ct − Ct−1) · Vt   — a rolling sum, not Granville's cumulative line
VWAPn = Σn(TP · V) / Σn V,  deviation = (C − VWAP) / VWAP   — TP = (H + L + C)/3
volume ratio = Vt / meann(V)   — current bar included in the average

The cumulative OBV line is a level whose value depends on where the series happens to start, so it has no finite tail reach and cannot meet the contract. obv_flow is the windowed adaptation: the rolling sum of signed volume over window bars. An unchanged close contributes 0, bar 0 is NaN because the sign needs the previous close, and the reach is window + 1. A window whose every contribution is exactly zero — a flat close patch or zero volume — reads exactly 0. Its market_physics twin is exact: obv_flow(window=w) equals volume_imbalance at the same window with direction_source="close_change" and normalize=False; at its defaults volume_imbalance signs by candle direction and normalises to [−1, 1].

vwap_deviation is the close's relative distance from a rolling VWAP of the typical price over the trailing window bars: positive above, negative below, with the zero cross as the canonical reading. Two degenerate windows read exactly 0 — a zero-volume window, where VWAP is undefined and no deviation can be claimed, and a completely flat OHLC window, where VWAP equals the price by identity. Its relatives in market_physics are the gravity family (gravitational_balance, orbital_deviation), which read the close against a rolling binned volume profile — the volume mass above versus below it, or its distance from the profile's centre — and market_potential_energy with equilibrium="vwap", which squares the close's displacement from a rolling VWAP centre and so loses the side.

volume_ratio divides the current volume by the rolling mean of the last window volumes, the current bar included, as the classic spelling has it. Around 1 is ordinary volume; a value such as 2 is the usual spike reference. A zero-volume window — which, with the current bar included, means the current volume is zero too — reads the neutral 1.0, so a spike threshold cannot fire on a dead market.

The snaps cover whole degenerate windows only. A window whose deviation or flow is zero for another reason — all of the window's volume printed at a typical price equal to the current close, or up and down volume that cancel exactly — is computed as it is, and a full pass and a tail pass can then disagree in the last bits around that zero.

When to reach for this family: participation in canonical form — the net direction of volume over a window, the close against its volume-weighted average, and whether the current bar's volume stands out from the recent norm.

reach

Indicator warm-up in the canon — lookback, unstable periods and exponential seed decay · 3 names

Every practitioner knows an indicator needs history before it means anything. TA-Lib splits that need in two: a lookback, the bars before the first output exists, and for indicators with memory — EMA, Wilder's RSI and ATR — an unstable period, the further bars during which the output still depends on where the data began. The reach module folds both into one published, per-parameter number. Its question is the one a streaming consumer asks on every bar: does a recomputation over only the last L rows give the value the whole history gives?

min_bars = min { L : |f(last L rows) − f(all rows)| ≤ max(1e-12, 1e-9·|f(all rows)|) }   — at the final bar
seed weight after L bars = (1 − α)L  ⇒  L(α, d) = ⌈ d · ln 10 / −ln(1 − α) ⌉   — d decades of decay
α = 2/(n + 1) for an EMA,  α = 1/n for Wilder's smoothing

For a fixed-window rolling statistic the answer is simple: once the window is full nothing older matters, so the reach is the first-valid index + 1 — 2·window for the two-layer ADX, window + smooth − 1 for stochastic %D, window + 1 where the previous bar is needed, the window itself elsewhere. An exponential average has no exact finite answer, because the seed never leaves the recursion. It does fade geometrically, though, and the gate is relative, so the module publishes the closed-form decay bound instead: 10 decades for ema and for Wilder-mode rsi (one spare decade over the gate's 9, plus one bar for the price difference in RSI), and 14 decades per stage for macd, whose slow EMA and signal EMA are summed as two stacked stages while its fast span plays no part. MACD's extra decades exist because its value crosses zero, where the gate falls back to its absolute 1e-12 floor.

Three names make up the module. ema_decay_bars(alpha, decades) is the bound itself and raises ValueError unless 0 < α < 1. min_bars(indicator, **params) takes a roster function's bare name and that function's own parameters, with omitted ones taking the function's defaults; an unknown name raises KeyError and an unknown parameter TypeError. MIN_BARS_DEFAULTS is the table at every function's defaults, built at import: 231 for ema, 564 for macd, 28 for adx and 15 for rsi — the Cutler default. Wilder RSI's 312 is min_bars("rsi", smoothing="wilder"), and the EMA class grows with its span: about 11·(w + 1) bars for an EMA, 2303 at span 200.

The published numbers are tested, within limits worth knowing. The library's suite measures each roster entry with a dense-L finder — L scanned upward from 1, three end points checked, a candidate accepted only when the next 25 values of L pass too — on one seeded random walk at the default parameters, and requires measured = published for the rolling class and measured ≤ published for the EMA class. Away from the defaults an EMA-class number is the formula's. min_bars does not validate parameter values (min_bars("sma", window=0) returns 0, an unknown smoothing falls through to the Cutler branch), and it raises for a span of 1, which ema, Wilder rsi and macd's signal_window accept. Wilder RSI is the weakest bound: on ten seeds, small windows (2 and 3) left some tails outside the gate at the published reach on every seed, while EMA(20), EMA(200) and MACD(12/26/9) stayed inside at every end point checked.

When to reach for this module: sizing a streaming tail or a warm-up — how many bars to keep, and from which bar an exponential indicator's value no longer depends on where the data began.
